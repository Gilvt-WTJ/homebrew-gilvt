# homebrew-gilvt

Homebrew tap for [gilvt](https://gilvt.com), a native macOS terminal for running, monitoring, and reviewing
parallel Claude Code and Codex sessions.

```sh
brew install --cask gilvt-wtj/gilvt/gilvt
```

gilvt updates itself through Sparkle, so `brew upgrade` is not needed. The cask is bumped by the release
workflow in [Gilvt-WTJ/gilvt](https://github.com/Gilvt-WTJ/gilvt).
